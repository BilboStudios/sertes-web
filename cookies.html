1. ¿Qué son las cookies?

Las cookies son pequeños archivos que un sitio web guarda en tu navegador o dispositivo cuando lo visitas. Sirven, por ejemplo, para que la web funcione correctamente o para recordar tus preferencias.

3. Qué cookies utiliza este sitio web

Este sitio web no utiliza cookies de analítica, de publicidad ni de seguimiento, ni propias ni de terceros.

Solo puede utilizar cookies técnicas estrictamente necesarias para que la web funcione (por ejemplo, para mantener la sesión o la seguridad del sitio). Según el artículo 22.2 de la Ley 34/2002 (LSSI-CE), estas cookies están exentas del deber de obtener tu consentimiento, por lo que no se muestra un banner de cookies.

Las fuentes tipográficas se cargan desde el propio servidor de este sitio, no desde servidores de terceros.

4. Enlaces a sitios de terceros

Esta web incluye enlaces a WhatsApp y LinkedIn. Al hacer clic en ellos accedes a sitios externos que pueden usar sus propias cookies, regidas por sus políticas, sobre las que el titular de esta web no tiene control.

5. Cómo gestionar o eliminar las cookies

Puedes permitir, bloquear o eliminar las cookies desde la configuración de tu navegador:

  • Google Chrome
  • Mozilla Firefox
  • Safari
  • Microsoft Edge

Si bloqueas las cookies técnicas, algunas funciones de la web podrían no funcionar correctamente.

6. Cambios en esta política

Si en el futuro se incorporan otras cookies (por ejemplo, de analítica), esta política se actualizará y, cuando sea necesario, se solicitará tu consentimiento antes de instalarlas.
